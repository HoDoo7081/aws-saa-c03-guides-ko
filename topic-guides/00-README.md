# SAA-C03 한국어 학습 목차

원작 RonitSachdev의 37개 주제 가이드를 한국어로 **요약·번역·재구성**했습니다. 문장별 완역은 아니며, 반복 비유·예제·복습 항목을 압축하고 일부 부정확한 단정과 오래된 기능 설명을 보완했습니다.

각 문서는 **개념 이해 → 핵심 개념 → 문제 유형 → 빠른 복습표** 순서입니다. 서비스명·API명·영어 시험 키워드는 함께 익힐 수 있도록 유지했습니다.

추천 순서는 원작자의 학습 순서를 따릅니다. 서비스별 출제 빈도나 아래 순서는 AWS 공식 배점표가 아닙니다. [번역 범위·정정 근거](../TRANSLATION-NOTES.md)를 먼저 확인하세요.

## 공부 방법

1. **첫 읽기:** 추천 순서대로 개념과 비교 기준을 이해합니다.
2. **두 번째 읽기:** 복습표의 오른쪽을 가리고 답과 선택 이유를 설명해 봅니다.
3. **모의고사 후:** 오답 주제의 문제 유형으로 돌아와 놓친 조건을 기록합니다.
4. **시험 직전:** 36번과 각 복습표를 훑고 익숙한 내용을 확인합니다.
